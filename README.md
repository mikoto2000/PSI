# PNG Structure Inspector

PNG と JPEG の内部構造を調べる読み取り専用のデスクトップアプリです。画像プレビュー、ファイル順のチャンクまたはマーカーの一覧、選択項目の詳細を表示します。

## 入手と起動

主対象は **Windows 11 x64** で、Windows 11 25H2 で動作を確認しています。macOS と Linux 向けにも CI でパッケージをビルドします。

GitHub のビルドが成功し、成果物が利用できる場合は、実行結果の **Artifacts** から `png-structure-inspector-windows-x64-installer` をダウンロードできます。ZIP を展開して `*-setup.exe` を実行してください。インストールせずに使う場合は `png-structure-inspector-windows-x64` を取得し、展開した実行ファイルを起動します。[GitHub Actions のビルド一覧](https://github.com/mikoto2000/PSI/actions/workflows/build.yml)

ソースから起動・ビルドする手順は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。

## 使い方

1. **画像を開く** でファイルを選ぶか、画像を 1 個ウィンドウにドロップします。
2. 一覧で PNG のチャンクまたは JPEG のマーカーを選びます。詳細にはファイル先頭からのオフセットと項目固有の情報が表示されます。PNG ではファイルに保存された CRC と計算した CRC も確認できます。
3. PNG の **テキストメタデータ** では、同一 Keyword の項目もファイル順に個別表示します。JSON 本文は **整形 JSON** と **元のテキスト** を切り替えられ、コピーすると現在の表示形式の本文がクリップボードに入ります。

画像を開いた後は **←** で前の画像、**→** で次の画像へ移動できます。同じフォルダーの PNG / APNG / JPG / JPEG をファイル名順にたどり、先頭と末尾で止まります。

## 確認できる情報

### PNG / APNG

| 種類 | 表示内容 |
| --- | --- |
| `IHDR`, `PLTE`, `IDAT`, `IEND` | 画像ヘッダー、RGB パレット、画像データのサイズと CRC、終端 |
| `tEXt`, `zTXt`, `iTXt` | Latin-1 または UTF-8 のテキスト、Keyword、iTXt の言語タグと翻訳 Keyword、圧縮の有無 |
| `pHYs`, `gAMA`, `sRGB`, `cHRM`, `tIME` | ピクセル密度と参考 DPI、ガンマ、レンダリングインテント、色度、UTC 更新日時 |
| `iCCP`, `eXIf` | ICC プロファイルのヘッダー概要、Exif の TIFF バイト順と最初の IFD の概要 |
| その他 | 名称、サイズ、オフセット、CRC、Critical / Ancillary、Public / Private、Safe-to-copy。未知の Critical チャンクには警告を表示 |

### JPEG

JPEG ではマーカーの種類、データサイズ、オフセット、画像寸法、コメントを確認できます。JFIF のバージョンと Exif / XMP / ICC プロファイルの識別情報も表示します。マーカー構造は [ITU-T T.81](https://www.w3.org/Graphics/JPEG/itu-t81.pdf) に基づきます。

## ファイルに問題がある場合

ファイルの先頭から PNG または JPEG と判定できない場合は、開くときにエラーが表示されます。途中で切り詰められた画像やデータ長が不正な画像は、読み取れた項目と構造警告を確認できます。プレビューや個別項目の詳細を表示できない場合も、読み取れた構造は閲覧できます。

## 既知の制限

- 走査は 20,000 チャンクまたはマーカーで停止し、一覧は 200 件ずつ表示します。
- PNG のテキスト、ICC、Exif の詳細入力と圧縮ストリームの展開は、それぞれ 4 MiB が上限です。
- プレビューは静止 PNG と 8 ビットの JPEG（SOF0 / SOF1 / SOF2）が対象です。上限はファイル 8 MiB、1,200 万画素、各辺 16,384 ピクセルです。PNG の圧縮メタデータには合計展開サイズ 8 MiB の上限もあります。APNG や上限を超えた画像も構造は閲覧できます。
- JSON の整形はネスト 120 段、出力 8 Mi UTF-16 コード単位までです。上限を超えた本文は元のテキストを表示します。
- ICC と Exif は概要表示です。構造検査は基本的な順序、終端、CRC と対応するメタデータを対象とし、画像データの表示可否は WebView のデコーダーが判定します。
